## 📤 HOW TO UPLOAD TO GITHUB

### Step 1: Create the Repository on GitHub
1. Go to https://github.com/extragaming4949-code
2. Click the "+" icon (top right) → "New repository"
3. Repository name: **Birthdaywish** (exact spelling!)
4. Description: "Birthday wish website for Shona Baby"
5. Make it **Public** (so you can share the link)
6. ❌ DON'T initialize with README, .gitignore, or license
7. Click "Create repository"

### Step 2: Upload Your Files
Open PowerShell/Command Prompt in the BirthdayWish folder and run these commands:
(The folder is already set up with git, so just run this command):

```bash
git push -u origin main
```

If it asks for credentials, enter your GitHub username and password/token.

## 🌐 HOW TO GET A SHAREABLE LINK (GitHub Pages)

After uploading to GitHub, follow these steps to get a live website link:

### Option 1: GitHub Pages (FREE & RECOMMENDED)

1. **Go to your repository:**
   https://github.com/extragaming4949-code/Birthdaywish

2. **Enable GitHub Pages:**
   - Click "Settings" (top menu)
   - Scroll down and click "Pages" (left sidebar)
   - Under "Source", select **main** branch
   - Click "Save"

3. **Get your link:**
   - Wait 1-2 minutes
   - Your link will be: **https://extragaming4949-code.github.io/Birthdaywish/**
   - Copy this link and share it with Shona Baby!

### Option 2: Quick Share (Alternative - Netlify Drop)

1. Go to https://app.netlify.com/drop
2. Drag and drop the entire BirthdayWish folder
3. Get instant link like: https://your-site-name.netlify.app
4. Share this link!
